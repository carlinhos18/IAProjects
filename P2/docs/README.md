OVERALL:
Pedagogical Goal
Develop a basic understanding of the opportunities and challenges of developing a machine learning project in the real world.

Scenario
Your group has just founded a startup for consulting machine learning projects. You found a potential client and you want to convince them them to hire the company.

Project Goal
Develop a POC addressing a low-hanging fruit problem:

identify and describe the problem
develop a model using artificial data
develop a web app illustrating the application of the model
The template Powerpoint file provided in moodle contains additional information about what is expected.

Identification of the Problem
Find someone whom you know who participates in a company with potential problem (company, public organization, ONG, …) and who is willing to play the part of the contact person.

## Slide 1
customer name
name and short description of the customer
name and role of the contact person

## Slide 2
problem
definition of the problem
short description of the current approach to address it

## Slide 3
available
high-level description of the data that would be available
e.g. entities or tables

## Slide 4
solution overview
description of the solution designed to address the problem
probably including other components besides the ML model
… such as mobile apps, websites, hardware
… and other AI techniques
e.g. search

IMPORTANT NOTE: you are not expected to develop the whole application. Just the predictive model.


## Slide 5
predictive model
description of the model
i.e. target variable
attributes

## Slide 6
empirical study: setup
summary of experimental setup
artificial data generated
model evaluation process
evaluation measures
performances estimation methodology

## Slide 7
empirical study: results
e.g. 3 algorithms

## Slide 8
stakeholders
list of roles in the organization that need to be involved for the successful development of the project

## Slide 9
expected challenges during development and deployment
technical 
e.g. lack of reliable data
organizational
e.g. opposition of users


## Slide 10
unavailable data
high-level description of additional data that should be available
challenges involved in collecting it

## Slide 11
ethical risks
what are the ethical risks involved in using the proposed solution
